# Techno It - iOS Style Calculator

A calculator UI inspired by the iOS calculator with:

- iOS-like dark styling and button colors
- `Techno It` heading
- Full basic operations (`+`, `−`, `×`, `÷`, `%`, sign toggle, decimal, equals)
- Expression history line above the main display
- Press feedback animation on each button click

## Run

Open `index.html` in a browser.
